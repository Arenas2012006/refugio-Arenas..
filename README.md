# refugio-Arenas..

**REFUGIO ANIMAL**

*Qué es esto?*
> Es una simulacion de un refugio de animales 
## REQUISITOS
> Tienes que tener instalado cowsay 
> Tienes que tener instalado python 3.14.6

## INSTALACION 

1. Clona el repositorio:

```bash
git clone https://github.com/Arenas2012006/refugio-Arenas...git
```

2. Entra a la carpeta del proyecto:

```bash
cd refugio-Arenas..
```

3. Instala las dependencias:

```bash
pip install -r requirements.txt
```

## EJECUCION

Con las dependencias instaladas, corre el proyecto con:

```bash
python main.py
```
